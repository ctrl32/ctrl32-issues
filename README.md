# ctrl32-issues

The public bug tracker for [ctrl32](https://ctrl32.com).

**There is no code in this repository.** The ctrl32 editor and runtime are
closed source. This is simply the place where problems are reported in the
open, and where you can see what is already known, what is being worked on,
and what has been fixed.

### Report a bug
**[→ New bug report](https://github.com/ctrl32/ctrl32-issues/issues/new?template=bug_report.yml)**

Search the [open issues](https://github.com/ctrl32/ctrl32-issues/issues)
first — if yours is already there, add a comment with your board and version
rather than opening a second one. It genuinely helps to know how many people
are hitting the same thing.

### Ask for a feature
**[→ New feature request](https://github.com/ctrl32/ctrl32-issues/issues/new?template=feature_request.yml)**

## What goes somewhere else

| If you want to… | Go here |
|---|---|
| Ask how to do something | [Forum](https://ctrl32.com/forum) — other users can answer too |
| Sort out a licence key, an order or an invoice | [Contact form](https://ctrl32.com/contact) — **never in a public issue** |
| Add your board to the catalogue | [`ctrl32-hardware`](https://github.com/ctrl32/ctrl32-hardware) — it is a pull request |
| Look something up | [Documentation](https://ctrl32.com/docs/) |

## What to expect

This is a one-person project. Reports are read, and reproducible ones get
fixed — but there is no support contract behind this repository and no
promised response time, on any licence tier. A clear report with a project
file attached moves far faster than a vague one, simply because it can be
reproduced without a conversation first.

Fixes ship in the normal releases. Watch this repository (**Watch → Custom →
Issues**) if you want to be told when something you reported closes.

## One thing worth repeating

Project files store what you typed into them — Wi-Fi passwords, MQTT broker
credentials, IP addresses. Before you attach one to a public issue, open it
and take them out, or build a stripped-down copy that still shows the
problem. Once it is posted here, it is public and indexed.
